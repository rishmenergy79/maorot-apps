# העלאה ל-Netlify

## הדרך המהירה (2 דקות, בלי כלים)
1. היכנס ל-app.netlify.com → Add new site → **Deploy manually**
2. גרור לתוך החלון את **התיקייה כולה** (index.html + netlify.toml + _redirects)
3. תקבל כתובת מסוג `https://xxxx.netlify.app` — זהו, האפליקציה חיה

## עדכון גרסה
Site → Deploys → גרירת התיקייה המעודכנת. הכתובת נשארת זהה.

## מה נפתח ברגע שעוברים ל-https
- כניסה ביומטרית (טביעת אצבע / זיהוי פנים) — עובדת
- קליטת מיקום GPS ללינק וואיז — עובדת
- אפשר להוסיף את האפליקציה למסך הבית בטלפון ולהפעיל כמו אפליקציה רגילה

## הוספה למסך הבית
אנדרואיד: תפריט ⋮ → "הוספה למסך הבית"
אייפון: כפתור שיתוף → "הוספה למסך הבית"
