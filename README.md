# מאורות — מרכז האפליקציות 🌞

דף ריכוז אחד (hub) שמציג את כל האפליקציות של מאורות במקום אחד, ניתן להתקנה על נייד ומחשב (PWA).

---

## 📁 מבנה התיקייה

```
index.html            ← דף הריכוז הראשי
manifest.json         ← הגדרות ההתקנה של דף הריכוז
sw.js                 ← service worker (מאפשר התקנה)
icons/                ← אייקונים של דף הריכוז
off-grid/             ← אפליקציית Off Grid (שלמה)
taom-techni/          ← אפליקציית תיאום טכני (שלמה)
```

"חיבור מונים" הוא קישור חיצוני (Google Apps Script) ולכן אין לו תיקייה — הוא מוגדר בתוך `index.html`.

**רקע וידאו:** `bg.mp4` (עם תמונת גיבוי `bg-poster.jpg`) מנגן ברקע דף הריכוז. כדי להחליף את סרטון הרקע — פשוט החליפו את `bg.mp4` בקובץ אחר באותו שם.

## 🚀 איך מעלים ל-GitHub Pages (חינם)

1. היכנסו ל-https://github.com והתחברו (או פתחו חשבון חינם).
2. לחצו על **New repository**. תנו שם, למשל `maorot-apps`, ובחרו **Public**. לחצו **Create repository**.
3. במסך הריק לחצו על הקישור **"uploading an existing file"**.
4. גררו לתוך החלון את **כל** הקבצים והתיקיות מתוך תיקיית `site` (כולל `index.html`, `off-grid`, `taom-techni`, `icons`).
5. לחצו **Commit changes**.
6. בראש המאגר → **Settings** → בתפריט הצד **Pages**.
7. תחת **Branch** בחרו `main` ותיקייה `/ (root)`, לחצו **Save**.
8. המתינו כדקה. הכתובת שלכם תופיע בראש עמוד ה-Pages, בערך כך:
   `https://<שם-המשתמש>.github.io/maorot-apps/`

זהו! הכתובת הזו היא ה-URL הקבוע שממנו נכנסים לכל האפליקציות.

## ➕ איך מוסיפים אפליקציה חדשה בעתיד

1. העלו את תיקיית האפליקציה החדשה לצד הקבצים האחרים (למשל תיקייה בשם `my-new-app`).
2. פתחו את `index.html`, מצאו למעלה בקוד את המערך `const APPS = [ ... ]`.
3. הוסיפו אובייקט חדש, למשל:

```js
{
  name: "שם האפליקציה",
  sub: "כותרת משנה",
  desc: "תיאור קצר של מה האפליקציה עושה.",
  url: "my-new-app/index.html",       // או כתובת מלאה https://... לאתר חיצוני
  icon: "my-new-app/icon-512.png",
  external: false                       // true אם זה קישור לאתר חיצוני
}
```

4. שמרו, העלו את השינוי ל-GitHub — והכרטיסייה החדשה תופיע אוטומטית.

## 📲 התקנה על נייד / מחשב

כל אפליקציה (וגם דף הריכוז עצמו) ניתנת להתקנה:
- **אייפון:** פתחו ב-Safari → כפתור שיתוף → "הוסף למסך הבית".
- **אנדרואיד:** פתחו ב-Chrome → תפריט → "התקן אפליקציה".
- **מחשב:** פתחו ב-Chrome/Edge → אייקון ההתקנה בשורת הכתובת → "התקן".
